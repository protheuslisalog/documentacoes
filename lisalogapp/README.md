## 1. Acesso

### 1.1. Cadastro

Ao abrir a tela principal, toque em “cadastre-se”.

Preencha todos os campos e acione o botão “CADASTRAR”:

Filial Lisalog = Código da filial da Lisa

Usuário (login) = Login de acesso (deve ser o mesmo usado para acessar o Protheus)

Nome = Nome completo

E-mail = Qualquer e-mail válido

Senha = Senha de acesso (deve ser a mesma usada para acessar o Protheus)

![image002](/documentacoes/lisalogapp/imagens/image002.png)

Figura 1 - Tela de login opção cadastre-se

![image003](/documentacoes/lisalogapp/imagens/image003.png)

Figura 2 - Cadastro para efetuar o login

### 1.2. Login

Para acessar o App, basta informar o e-mail e a senha previamente cadastrados e acionar o
botão “ENTRAR”.

Figura 3 - Realizando login

## 2. Expedir Romaneio

Acesse o menu superior esquerdo, que irá expandir as opções disponíveis no App, e escolha “Expedir
Romaneio”.

![image008](/documentacoes/lisalogapp/imagens/image008.png)

Figura 7 - Menu lateral

![image009](/documentacoes/lisalogapp/imagens/image009.png)

Figura 8 - Opção Expedir Romaneio

Será aberta a tela para entrada dos dados do Romaneio de saída.

Primeiro, informe o código do Romaneio e acione o botão Atualizar para carregar os dados
dos pedidos.

![image010](/documentacoes/lisalogapp/imagens/image010.jpg)

Figura 9 - Buscando informações de pedido do Romaneio

![image011](/documentacoes/lisalogapp/imagens/image011.png)

Figura 10 - Informações dos pedidos do Romaneio

É possível escanear o código de barras para capturar o código do Romaneio acionando o botão
com a imagem de um scanner.

![image012](/documentacoes/lisalogapp/imagens/image012.png)

![image013](/documentacoes/lisalogapp/imagens/image013.png)

Preencha os demais campos conforme a necessidade.

É possível anexar arquivos de imagens ou fotos ao Romaneio. Para isso, toque no ícone do clipe
para selecionar um arquivo já existente no dispositivo ou no ícone da câmera para tirar uma
foto.

![image014](/documentacoes/lisalogapp/imagens/image014.png)

Figura 13 - Opções de fotos e anexos do Romaneio

![image015](/documentacoes/lisalogapp/imagens/image015.png)

![image017](/documentacoes/lisalogapp/imagens/image017.png)

Figura 16 - Enviando informações para Expedir Romaneio

Será apresentada a pergunta se deseja coletar uma assinatura. Caso a resposta seja “sim”, uma

![image018](/documentacoes/lisalogapp/imagens/image018.png)

Figura 17 - Informando se deve colher assinatura

## 12. Expedição

Acesse a opção “Expedição” e, para iniciar a expedição (embarque) dos Romaneios, informe o
CNPJ da transportadora ou o código do Romaneio e acione o botão de pesquisa localizado ao
lado.

![image083](/documentacoes/lisalogapp/imagens/image083.png)

Figura 82 - Informando Romaneio para iniciar expedição

Serão listados todos os romaneios fechados da mesma transportadora do romaneio informado.
Caso seja informado o CNPJ da transportadora, serão listados todos os romaneios fechados
dessa transportadora.

Insira todos os romaneios apresentados para a finalização da expedição e acione o botão
FINALIZAR TRANSPORTADORA. Se todos os romaneios estiverem confirmados, será solicitada
a assinatura. Colete a assinatura e acione o botão ENVIAR para concluir a expedição dos
romaneios.

![image084](/documentacoes/lisalogapp/imagens/image084.png)

Figura 83 - Finalizando expedição de transportadora

![image019](/documentacoes/lisalogapp/imagens/image019.png)

Figura 84 - Finalizando expedição de transportadora

Caso haja necessidade de justificar a não expedição de algum Romaneio, pressione a linha do
registro desejado, informe a justificativa e as observações.

![image086](/documentacoes/lisalogapp/imagens/image086.png)

Figura 85 - Justificando a não expedição do Romaneio

Para verificar se todos os Romaneios de um determinado cliente foram informados para a
expedição, acione o botão VALIDA ROMANEIOS CLIENTE, selecione o cliente e pressione Ok.

![image087](/documentacoes/lisalogapp/imagens/image087.png)

Figura 86 - Verificando Romaneios em Aberto selecionando cliente

![image088](/documentacoes/lisalogapp/imagens/image088.png)

Figura 87 - Verificando Romaneios em Aberto mensagem com Romaneio em aberto

Figura 89 - Selecionar a opção desejada
